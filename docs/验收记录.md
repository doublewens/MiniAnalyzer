## 三、使用方式

进入ZIP解压后项目根目录：

```bash
python -m pytest -q
python main.py examples/ir/live_loop.ir --analysis live
python main.py examples/ir/live_loop.ir --analysis live --trace text
python main.py examples/ir/live_loop.ir --analysis live --trace text --trace-output trace.txt --output result.json
python main.py examples/ir/live_loop.ir --analysis live --trace jsonl --trace-output trace.jsonl
```

详见：`docs/interfaces_v04_M1M2.md`、`docs/teacher_demo.md`。

## 四、重要范围说明

- 目前是**指令级**CFG，并非基本块级CFG。
- 输入是课程Teaching IR，**不能**直接分析C或Mini-C源文件。
- 保留v0.3的**调度全部节点**策略，包括不可达节点；此时的结果解读须注意不可达节点带来的近似。
- M1/M2只做教学观察，并未加入任何新的分析算法；Reference/Student模式必须等待M3/M4。
- `statistics.iterations`统计“处理节点次数”，不是完整的全图迭代轮数。
- Observer只作为旁路，不负责控制Worklist的调度。
